# Timeline Frontend (wrapped demo)

Scaffolded Vite + React + TypeScript + Tailwind project.

Quick start:

1. cd timeline-frontend
2. npm install
3. npm run dev

The app provides a small form to call the backend endpoint:
`GET https://timelinebackend-2f2f.onrender.com/api/timeline/{userId}/{year}`

If you will provide OAuth/test token, paste the token into the form's token field (will be sent as `Authorization: Bearer <token>`).
